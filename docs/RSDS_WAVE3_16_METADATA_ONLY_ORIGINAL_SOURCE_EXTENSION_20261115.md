# RSDS Wave3 — 16 new source identities, metadata-only freeze (2026-11-15)

## What is and is not new

Wave1+Wave2 included **35 independently registered Movebank source study IDs**, but only **10** had every registered native taxon's original DAY–NIGHT q estimable and **8** had the corresponding q–daylength relationship. Among 10 source-complete q respondents, 7 were positive and 3 negative; the respondent-only mean changed sign when source composition changed. The held-out 48-source irradiance→heading sign remained **NOT REPLICATED**. These are historical outcomes and must not be reclassified.

**This Wave3 action selects, but does not open or analyze, 16 new original source studies.** To avoid species-by-species result chasing it uses the *unchanged original 2026-10-19 catalog SHA order*, selecting single-native **ranks 25–40** immediately after the existing 24 selected single-native candidates. All 11 multi-native metadata-priority candidates have already been included in Waves 1–2, and are not repeated.

## Required safeguards

1. **No GPS or provider file access in this route.** The generated roster contains source DOI/study ID, frozen public taxon metadata and rank SHA only. No original animal IDs, timestamps, tracks, q or individual bootstrap estimates.
2. **No replacement on failures.** Once new identities are frozen, large files, invalid licensing, human-location data, unusable cadence, schema errors or insufficient paired DAY/NIGHT animal-days remain explicit source HOLDs.
3. **Human data never opened.** Any selected `Homo sapiens` metadata identity is a permanent source no-contact HOLD, not an animal movement observation.
4. **Explicit adaptive-quota caveat.** Wave3 quota was chosen *after* Wave1 and Wave2 results, even though the individual identities use the original metadata-only SHA ranking. It is not a fully preregistered global probability sample.
5. **Separate biological endpoints.** Source-mean q (log1p GPS speed at NIGHT minus DAY) is neither true activity fraction nor solar-navigation behavior. New eventual outcomes must keep the old full-native-tag/source estimand, source study-ID as unit, and all 51 attempts including unavailable; any wildlife/domain exclusion must use original metadata, not favorable q signs.

## Next independent data stage

**First** freeze the 16-source identity JSON by successful source-only CI and commit. **Then**, in a new, separate route, read only provider-original source file metadata/MD5/size and decide eligible versus permanent HOLD **before any new GPS access**. Once those records are frozen, the unchanged original GPS estimator can evaluate the new source studies, with an outcome-blind species/domain ledger and study-level sample nonresponse. No inference about a universal nocturnal or solar effect is licensed by metadata selection itself.
