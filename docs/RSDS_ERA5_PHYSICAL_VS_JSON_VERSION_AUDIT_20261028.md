# ERA5の生JSON SHAと時別気象数値版の同一性を分ける

**RSDS｜2026-10-28｜既存の生物学的結果は変更しない独立した気象データ監査。**

## 固定2地点で得た新しい実証結果

元GPS調査地とは無関係な公開固定2地点を選び、Open-MeteoのERA5を**同じUTC時間・同じ変数・同じモデル・同じ地点**の条件でそれぞれ2回取得した。

| 数値版の監査 | 北半球2020年（8784時間） | 南半球2021年（8760時間） |
|---|---:|---:|
| 生HTTP JSONのSHA256 | **不一致** | **不一致** |
| UTC時刻・対象4変数の単位・時別数値の正規化SHA256 | **一致** | **一致** |
| ERA5返却モデル格子メタデータ | 一致 | 一致 |
| 数値が異なる時間数（短波放射・気温・風速・風向） | 全4変数とも **0** | 全4変数とも **0** |

**肯定的に確認できたこと：生JSONのSHA不一致と、物理的なERA5短波放射・気温・風の時系列の変更は同じではない。** JSON全体には計算時間などの動的メタデータ・空白・数値書式などが含まれ得る。SHAの不一致だけで元の時別気象数値が変わったとは判断できない。

## これまでのUtah/Wyomingの12コンテキストとは異なる推論対象

従来の同一標識個体×日射解析では、以前に取得したERA5の「生JSONバイト列のSHA256」と再取得したJSONのSHA256が**12/12コンテキストで不一致**だった。そのため歴史的な別ルートで**ERA5_VERSION_HOLD**を保持し、個体内の気象バージョンに依存する効果比較を停止した。

しかし、**その当時の旧ERA5時別数値配列そのものはRSDSに保存されていない**。昔の原SHAだけから旧数値を逆算できないため、今回の固定2地点が「生JSON不一致・数値一致」であったことを理由に**昔の12件の物理数値も同一だったと後付け判断してはならない**。旧日射×移動方向の結果も未取得値を新しいゼロに変えない。

旧12コンテキストは **HOLD（旧生JSON同一性が不成立、旧物理値の再現性は未同定）** のまま。それとは別に**新しいERA5数値版を現在から固定する**研究ルートを作成した。

## 正規化と新しい元GPS研究への接続

新しいphysical SHA256に含めたのは、ERA5フル暦年のUTC時刻（8760/8784連続時刻）と、以下4変数の名前、単位、欠測位置、数値を小数6桁まで正規化した配列である。

- wind_speed_100m（m/s）
- wind_direction_100m（°、FROM方向）
- shortwave_radiation（W/m²）
- temperature_2m（°C）

実際の格子メタデータは別途比較し、位置・解像度が変わっていれば物理値のSHAが一致しても明示的に警告する。旧研究より細かい不一致原因を推定できるよう、各変数で値が異なるUTC時間の件数と最大絶対差も記録する。元のGPS座標・個体ID・正確な観察時刻・移動速度系列は出力しない。

Utah 4分類群・Wyoming 2分類群に対応する、**以前に元GPSの日数で選択した12個の1°グリッド×暦年コンテキスト**へは、別の[原GPSコンテキスト監査コード](../scripts/audit_rsds_era5_original_source_physical_v1.py)で適用する。原Movebank bitstream UUID・bytes・MD5を照合、元個体年内の昼夜GPS qと日長係数、採用個体数、元コンテキストのq適格日数・GPS太陽方位ステップ数を**新ERA5取得の前**に再現する。同じ元気象グリッド×年を2回取得して現在のraw SHAと数値版SHAを比較する。元のグリッド中心・UTC年・個体・GPSデータは公開しない。

## 科学的な解釈の境界

今回のデータ版の成功は、**気象データの物理数値を正確に固定できる条件を実証**した技術的・科学的品質結果である。現在の太陽相対移動方位や時間ニッチの新しい気温／放射因果効果を証明したものではない。

RSDSにおける主要な生態学結果――**8公表原GPS調査・12調査×分類群における昼夜GPS変位の非一様性、推論単位で変わるsource-equal全体平均、地理的方位marginalと太陽方向covarianceの分離**――は変更しない。48原日射調査の負方向の事前指定外部再現結果 **NOT REPLICATED**、旧12 ERA5生JSON版HOLDも変更しない。

次の真の生態学検証には、新たに凍結した気象数値版を元個体・元時刻のGPSに結合する独立ルートが必要であり、旧モデルとの違いは**気象データ版が違う再解析**として正直に報告する。
