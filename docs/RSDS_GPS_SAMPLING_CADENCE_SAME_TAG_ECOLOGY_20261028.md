# RSDS — 日射・日長・時刻と移動ニッチ：GPS観測間隔をそろえた実測の感度分析

**2026-10-28｜原Movebank 8研究・12 study×taxon行／原イベント閲覧後に固定した観測過程の事後感度。**

## 中心となる問い

> 世界の生物間で観測された昼夜移動・日長関係の異質性は、個体の時間利用そのものの違いなのか。それとも記録装置の観測間隔が異なることから部分的に生じるのか？

**このルートは機構的な日射反応を推定しない。** 既存のq指標 \(q=\log(1+\widetilde{v}_{night})-\log(1+\widetilde{v}_{day})\) は、時間帯ごとのGPSの**最短直線変位速度**を使う。GPS測定間隔が長いほど、移動経路の曲がりや往復を見逃し、同じ動物でも見かけの直線速度が変わり得る。よって、それぞれの元研究で一定の1時間ソース原測定を別の間隔でサンプリングすると、qおよびq~天文日長の係数がどの程度変わるのかを直接検証する。

## 固定済みの原調査

以前の公表8原調査・12 study×taxon行（Utah4分類群、Wyoming2分類群、新6原調査で6分類群）をすべて使用する。新6研究の元ファイルMD5は事前結果閲覧前に固定済みであり、ダイサギ1原調査は元200MBサイズ上限超過のため**同じHOLD**に残す。元study DOI/動物学名／ビットストリームを入れ替えない。

## 同じ元タグ・年・観測日を用いる比較

1. 元の公開元GPSをUUID/ファイルサイズ/MD5で照合し、以前の1時間ソースデータに基づく元q平均とq~日長係数・適格個体数をすべて数値再現する（これが通らない場合は**SOURCE_HOLD**）。
2. 元の各UTC時間帯からタイムスタンプだけで採用された1個のGPS位置を元に、1時間の原データを**UTC偶数時だけ**と**UTC奇数時だけ**に別々に間引く。2時間間隔の受信位置の間は補間しない。
3. 元の1時間系列は受信間隔0.5〜2.0時間、新しい2時間系列では1.5〜2.5時間とする。実際の受信位置から直線変位速度km/hを計算し、全区間で始点・中点・終点が同じ天文日付・昼夜区分でなければ除外する。速度上限60km/hは元と同じ。
4. 1時間系列と各2時間系列の**両方に3本以上の昼GPS区間と3本以上の夜GPS区間がある元個体・元日**だけを残す。元個体年内で両方に10日以上、日長傾きではさらに日長0.5時間以上の変動を求める。2時間に間引いた結果失われた元タグ・日数・適格傾きも漏らさず記録する。
5. **同じ元個体・年・日だけ**で新旧qと同じ日長xに対する傾きを計算し、各元タグにおける **2h−1h** の差を先に求める。元タグ5個以上の時だけ元タグbootstrap2000回の未補正95%区間を報告する。

**注意：** 2h−1hの符号が負でも「動物が夜行性から昼行性に変化した」という意味ではない。同じ動物の同じ日を違う時間幅で観測すると結果が変わるという測定問題に対応する。UTC偶数時・奇数時は「朝／夜」「太陽への接近／忌避」の比較ではない。

## マクロ生態学的な意味

元8調査は同一の観測プロトコルを採用した世界標本ではない。今回の観測間隔によるqの変化と、原study DOIごとの採用タグ率・日数の低下を、元8研究の生態学的異質性と区別する。この分析で残る関連は、「同じ採用日で直線変位速度の測定間隔を変えても記述結果が保たれる」範囲に限定する。独立した生態学的因果機構・種適応・潜在活動時間の同定は別のモデル／観測努力が必要。
