# RSDS — 8原GPS調査から見た時間利用・日長・太陽相対移動方向の一般性

**2026-10-26｜RSDS原データマクロ生態学 v1｜事前固定された新規6調査＋既存2調査。**

## 現在の研究質問

> 太陽・季節・環境の変化に対して、生物の時間利用と移動方向はどのように組織化され、その違いは種や地域を越えて一般化するのか？

RSDSでは天文日長 \(L\)、太陽方位 \(A\)、元GPS観測時刻、元移動方位 \(B\)、昼夜観測GPS最短移動速度を分ける。今回の比較は、旧2原調査（Utah/Wyoming）から、新しい6原Movebank調査（野生シチメンチョウ、ボブキャット、アカギツネ、スナドリネコ、ダイサギ、コアラ）への**初めての地域・移動生態群拡張**である。

新6調査は前の生態学的結果を見た後に選定しているので、完全な独立の事前仮説テストではない。しかし**新6件のGPSイベント内容を見る前**に、原UUID・DOI・学名・元study ID・200MBサイズ上限と計測法を固定し、原ファイル提供者MD5とファイル名も結果を見る前に凍結した。6調査すべてを残し、ダイサギの原GPSファイルが426 MBを超えた点は**ソースHOLD**とする。調査は生態群・地域に幅を持たせた**意図的な非確率標本**で、世界の動物群から無作為抽出していない。

### 対応づけた時間・方向の元GPS計測

\[
q=\log(1+\widetilde v_\mathrm{NIGHT})-\log(1+\widetilde v_\mathrm{DAY})
\]

速度は受信されたGPS移動区間の**直線最短変位速度 km/h**。負は昼の記録変位速度が相対的に大きく、正は夜の記録変位速度が相対的に大きいという観測的指標であって、真の昼夜活動時間の割合・採食時間とは**違う**。

\[
Y_{\parallel}=\cos(B-A),\qquad
Y_\perp=\sin(B-A)
\]

これらは**GPS変位移動方位**を瞬間の計算太陽方位と比較しており、動物の体軸・目線・太陽コンパス・被日射の選択を測っていない。太陽相対cosは、元移動の地理的方位marginalと、地理的移動方位と太陽方位のjoint circular covarianceを区別する。

## 3. 方位への一般化は限定的

元ソース方位の生cosについて、原GPSと元タグbootstrapがある10行のうち**2行が正、2行が負、6行の区間が0を含んだ**。残るスナドリネコの太陽方向（適格タグ3）とダイサギ（元ファイル200MB上限HOLD）は非推定。これを正負ゼロの三択の種特性に置き換えない。

*Joint*地理的GPS方位–太陽方位の結合成分については、古い6行にはこの統合に必要な元タグbootstrap区間が保存されていないので**点推定のみ**、今回推定できた新4行はすべて区間が0を含む。したがって「全10行でjoint効果はゼロ」は**不正確**であり、結論にしていない。

同じ元タグの2観測環境を確保できた新原調査は、野生シチメンチョウ8個体、ボブキャット6個体、コアラ5個体。英国アカギツネは元個体を同2環境で対応づけられず、スナドリネコ・ダイサギでもペア方向比較は非推定。繰返し元タグであっても、2コンテキストは元q記録日と個体重複数で選ばれており、**温度・日射量・太陽高度の同一勾配に沿う**2地点ではない。

## 4. 生態学的に意義のある中心主張と、まだ未同定なこと

**現段階で支持された記述的主張：** 天文日長に伴う観測された日周の移動変位の組織化は、元研究・生物群をまたいでも一つの方向にはならない。実測GPS方位の太陽相対平均についても全原調査に共通する符号を示さず、地理的移動経路marginalと太陽方位のjoint成分を分けないと生態学的解釈を誤る。時間軸と移動方向軸はそれぞれ**異なる一般性**を持つ可能性がある。

**現段階で支持されない主張：** 夜の真の活動時間が増えた、太陽方位を積極的に利用した、日射熱が行動を変えた、餌・競争相手や季節の生物間相互作用が媒介した、世界の生態系に共通の気候回避傾向がある、特定の種・ギルド適応である。研究全体の8原studyは生態学的な無作為標本でなく、同一研究内の4分類群を4独立生態系とみなせない。

## 5. 次の定量的進展

今回のマクロ記述を確証的な一般化に進めるには、元ファイルに対するGPS検出努力・観測cadenceの標準化、実測/再解析の気象の数値SHA版管理、元タグの同一個体内での環境の違い、地域・ギルド・季節の交絡を分ける新たな複数の独立元調査が必要。

特に、元短波放射と個体内移動方向の先行48原調査の**外部負方向事前指定再現は不成立**、Utah/Wyomingの再取得ERA5 JSON **12/12 SHAs不一致**を変更しない。今回の新GPS追跡結果は放射測定を再開しておらず、この過去のHOLDを新たな肯定的気候効果として読み替えない。
