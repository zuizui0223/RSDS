# RSDS — 原GPSで同じ標識個体が異なる観測環境を使ったとき、日射・時刻・方位の関係は再現するか？

**2026-10-26 / Utah + Wyoming / same original tagged-animal contextual sensitivity v1 / source-original observations.**

## 現在地と独立した科学的疑問

RSDSのv0では、Utah・Wyomingの公表元Movebank GPSを原プロバイダMD5照合後に再処理し、元のNIGHT−DAYログGPS速度差 q と q−日長傾きを全6分類群で完全再現した。さらに、**同じ元個体・元適格観測日**にERA5時別短波放射・風・気温とGPS移動区間をリンクした。

v0の特徴的な結果は、Utahビッグホーンの個体間平均について、太陽高度・真太陽時・月・風・気温を考慮した放射残差とcos(移動方位−太陽方位)が **+0.01686 [+0.00636,+0.02647]**、sin成分が **+0.02917 [+0.01765,+0.04126]** という記述的な原タグbootstrap区間を示したことである。しかし、6つのソース×分類群の**昼夜移動差qと日射残差**の関連は全群で原タグbootstrap区間が0を含み、1つの統一的「強光を避けて夜間に動く」法則は支持しなかった。

また、Wyomingビッグホーンの選択された2つの元1°グリッド×年コンテキストにおいて、放射残差と太陽直交方向sin係数は正負が逆となった。ただし**異なる標識個体の平均の反転か、同じ標識個体が環境によって応答を変えたのか**をこれまで検証していない。

### 今回の主目標

**同じ元個体で測定可能な2コンテキストのペア差だけを取り出して、異質性を実証できるか判断する。**

1. 元の2研究・6分類群のGPSソースID／ファイルサイズ／MD5を照合し、v0に使われたq・日長係数・適格個体数をERA5照会前に完全再現する。
2. v0と**全く同じ** q適格日・原1°グリッド×年の選択順位（元q適格動物数・日数のみで順位づけ）を復元し、元の太陽高度・時刻・移動区間ルールを維持する。
3. 以前のERA5原JSON SHA256が再取得結果と完全一致し、元の各コンテキストのcos/sin/q係数を数値再現した場合に限り、同一タグの重複を内部だけで集計する。
4. 同じ元タグが両コンテキストで同じ軸の効果を推定できる場合、**順位2−順位1**のタグ内係数差を求める。元標識個体のペアbootstrapを使用し、独立ソース数を水増ししない。

**重要：** 順位は元GPSの日数とタグ数によるもの。**より高い／低い日射量ではない**し、必ずしも先／後の季節を意味しない。正負の差に天文季節や温熱効果の原因を読み込まない。

## 必須の非肯定的結果

- 同じ個体が両コンテキストに存在しない、あるいは元の天文時刻・気象支持を満たさない場合：**INSUFFICIENT_PAIRED_ANIMALS**。生態学的な反転なしとみなさない。
- 以前のERA5生JSON SHAが異なる場合：**ERA5_VERSION_HOLD**。再解析の係数変化を生物の変化にすり替えない。
- 元GPS q−日長・元ERA5コンテキストの個体数／元効果が一致しない場合：**ORIGINAL_REPLAY_HOLD**。古い効果を後から書き換えない。
- 同じタグが複数の環境で見つかっても、元の地理的移動回廊・選別時刻・繁殖季節・微小生息環境を固定できないため、無条件の因果日射反応ではない。

## 初回実行の確定結果（2026-10-26）

[初回固定結果JSON](../research/RSDS_SAME_TAG_CONTEXT_PAIR_V1_FIRST_RESULT_20261026.json) と [GitHub Actions](https://github.com/zuizui0223/RSDS/actions/runs/40284603640) により、Utah・Wyoming両原GPS研究で**全6分類群のq・日長係数・元動物数がERA5新規照会前に数値再現**され、元のプロバイダGPS MD5も一致した。

しかし、6分類群×2選択コンテキストの**12/12で新規Open-Meteo／ERA5取得JSONの生SHA256がv0と一致しなかった**。気象系列の値が実際に変化したのか、JSON内の生成時刻などの周辺メタデータだけが異なるのかは、このSHA不一致だけでは区別できない。

契約どおり、12コンテキストすべてを **ERA5_VERSION_HOLD** に分類し、**q／太陽方向のペア差を推定した分類群は0/6**とした。個体内異質性の存在も不存在も、このルートでは判定していない。特に「Wyomingビッグホーンの2コンテキストの方向効果が個体内で反転する」とは**主張しない**。

**次の独立ルート:** 気象JSON版の問題と切り離して、元GPS・太陽高度・移動方位だけから、同じ元タグの複数コンテキストでの時間利用と地理的／太陽相対方向を直接比較する。気象については**新たな観測版**の天文・気象の数値配列（時刻・単位・変数）にハッシュを固定し、元のv0日射効果を上書きせず、別routeで再推定・差異診断する。SHA不一致を生物学的な結果や新しい負の再現として扱わない。

## 研究の階層と次のマクロ生態学的意味

原タグ間の新しい統計単位を得られれば、**個体内コンテキスト依存性**を推定する足場になる。ただし、1元ソースに多数タグがあっても地域単位は増えない。元のUtahとWyomingで同じ学名があっても、異なる個体群・GPS適格観測条件・ERA5地点に由来する可能性は残る。

**次の一般化テスト**は、(a) 同じタグの再現性と変化、(b) 同じ学名の別地域の異質性、(c) 飛翔動物や熱帯・島嶼データなど独立原ソースへの外挿を、それぞれ違う推論対象として組み立てること。世界共通の太陽コンパス行動を初期仮説に置かない。
