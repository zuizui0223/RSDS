# 原GPSが使った12環境コンテキストでERA5の気象数値版を検証

**RSDS｜2026-10-28｜Utah／Wyoming元標識GPS×ERA5の再現性監査 v1。**

## 実測結果：生JSON 12/12不一致・時別気象値12/12一致

以前の日射×移動方向解析に使った原Movebank GPS（Utah DOI 10.5441/001/1.711、Wyoming DOI 10.5441/001/1.703）について、**同じ提供元の元GPS bitstream UUID・ファイルサイズ・MD5**を検証し、元のq（NIGHT−DAY GPS直線変位速度差）とq~日長係数・適格個体数を**気象API呼出し前**に全6分類群で再現した。

その後、以前と同じ手法で**元q適格動物数と観測日数だけから順位づけられた、各分類群の2つの元GPSグリッド×年**を復元した。元q適格日数、動物数、太陽方位ステップ数は以前の第一次結果と一致していることを確認した。**環境値やGPS移動方向の符号でコンテキストを選び直していない。**

| 固定された元研究 | native taxon | 比較対象の元コンテキスト | 重複除去したERA5グリッド年の取得 |
|---|---:|---:|---:|
| Utah | 4 | 8 | 6 |
| Wyoming | 2 | 4 | 4 |
| **合計** | **6** | **12** | **10** |

この10件の元GPS選択グリッド年について、ERA5の**UTCフル年・短波放射・気温・風速・風向**をそれぞれ同一パラメータで2回取得し、12コンテキストに対応づけた。UtahとWyomingの原資料はすべてMD5再現、元のq/日長推定はすべて数値再現成功。

| 取得と再現性の検証 | 実測結果 |
|---|---:|
| 元GPS選択コンテキスト再現 | **12/12** |
| 元の初回JSON SHA256に一致した今回の生JSON | **0/12** |
| 今回の同条件2回取得で生JSON SHA256が不一致 | **12/12** |
| 今回の同条件2回取得でcanonical physical SHA256が一致 | **12/12** |
| 返却格子のメタデータも一致したコンテキスト | **12/12** |
| UTC時別4変数の値が変わった時間 | **0** |
| 以前の生JSON SHA保留の状態 | **HOLD 12/12のまま** |

結果は[元ソース完整12コンテキストのJSON](../research/RSDS_ERA5_ORIGINAL_SOURCES_CANONICAL_FIRST_RESULT_20261028.json) と [GitHub Actions成功ログ](https://github.com/zuizui0223/RSDS/actions/runs/40534683501) に固定した。取得先のモデル格子・元GPS個体ID・元観測年・イベント日時・座標を公開せず、各contextの原q資格と気象数値版のハッシュのみ保存した。

## 解釈：旧の版差HOLDは否定されず、現在の数値版の再現性が証明された

以前の旧ERA5 JSON自体のファイルバイト列が再取得版と異なることは正しい。ただし、その旧ファイルを研究リポジトリに保存していないため、昔の配列の値と現在の配列が一致していたかは不明である。**旧SHAだけから当時のshortwave/Wind/Temperature時系列を復元できない。**

今回同一リクエストを2回行った実測では、**12/12コンテキストで生JSONのSHAが異なったにもかかわらず、気象時別値は同じ**だった。つまり、取得したJSONそのもののSHAの変化はERA5物理数値の変化を証明するための条件ではない。そのため、**物理版のSHAをutc hour・単位・変数名・実数値（6桁）から別に作る**ことを今後の気象条件付き生態学検証の基本契約とする。

### 科学的主張の厳密な上限

- **支持された肯定的結果：** 元の実GPS解析用環境コンテキストに対して、現在取得できるERA5のUTC時別物理値は**12/12で繰り返し再現できる**。
- **未判定：** 過去の旧ERA5時別物理値と、今回の新しい物理値の完全一致。旧物理配列が残っていないため、過去の12件は再現判定未確定のままである。
- **未検証の生態学的仮説：** 動物が日射量に応じて移動方向や昼夜移動時間を変えたか。気温・風が媒介したか。今回気象数値版の一致は、同一個体の行動効果の再現でも気象変化のない環境で行われた介入試験でもない。
- **保存する失敗：** 旧の48原GPSソースで負方向の日射効果が外部再現しなかった判定は**NEGATIVE_DIRECTION_NOT_REPLICATED_IN_HELDOUT_SOURCE_SAMPLE**から変更しない。

## 次の同一個体×環境に関する解析契約

新しいcanonical ERA5数値版のSHAを使って、次は**新しいバージョンのモデル**として、元GPS個体・適格観測日と時別の shortwave/temperature/wind を結合する。日射量の残差を求める際は、真太陽高度・より細かい太陽時刻・季節・元地域を条件づけ、観測されたqやcos/sin(B−A)の**同じ元個体に対する係数**を先に規定する。

ただし、今回得られた現在の元グリッド年の数値版と以前の未保存旧気象版は同じ解析データだとは扱わない。古い先行効果との差異が出ても、気象版・元GPSの観測支援・日長・季節・個体の違いを分離する必要がある。元GPS日間のcadence／観測努力と利用可能なステップ速度の偏りも次に固定して監査する。
