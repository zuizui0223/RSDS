# 新たな物理数値版ERA5で再検証した、同一個体の日射・時間利用・太陽方向

**RSDS / 2026-10-28 / 元Movebank GPS同一2研究の新物理数値版による事後的再解析 v2。**

## 何を解決したか

以前のUtah/Wyoming原GPS×ERA5の短波放射モデルは、**元取得JSONと再取得JSONの生SHAの不一致**で、元の2コンテキストの日射係数差を「版差HOLD」としていた。過去のJSONの物理時系列自体が保存されていないため、旧ERA5の物理量が現在と同一だったかを確認できなかった。

今回、**元GPS MD5、元q（NIGHT−DAYログ直線変位速度差）、日長の係数、適格個体数、2元source q-観測支持コンテキスト**をすべて再現したあと、独立に数値版を固定した**12/12のERA5時別気象数値SHA**と一致した新取得ERA5だけを使った。元の推定器に対する新しい変数追加や閾値調整は行わず、元の月×1時間真太陽時計ブロック、太陽高度、高度の2乗、太陽方位、日長、ERA5気温・風速・風−太陽方向で条件づけたモデルを実行した。

### 係数の数値再現という肯定的結果

旧保存結果の**12元コンテキスト×3軸（日射残差とq、太陽相対移動cos、sin）の計36係数**と、今回の新しい物理版の推定値は、すべて**絶対差2.1×10⁻¹⁷以下**（機械精度）で一致した。6 native source-taxonomic group×3軸の**計18源元タグ群平均**も、最大差1.4×10⁻¹⁷程度で数値再現した。

これは、生JSONのSHAが過去と異なり、今回取得した2回のJSON SHAも変化するのに、**実際の保存済み統計係数は厳格な同一原GPS・同一推定器条件で再現可能**だったことを示す。旧ERA5物理配列の直接一致は保存データがないので今も判定不能であり、歴史的旧SHA保留は消さない。元研究を独立に増やしたものでもない。

各係数は**短波放射残差が100 W/m²増加したときの元観測指標の関連係数**。同じ元タグの系列・月・1時間太陽時計、太陽高度・方位、気温・風の調整を行っているが、動物が日射を直接受けた量や太陽を利用した原因ではない。

## 新しい個体ペアのコンテキスト差

以前の厳格な生JSON版一致に代えて、**今のERA5数値版の完全なUTC時別物理SHA一致**を確認した上で、同じタグが2つの元q適格コンテキストで効果を推定できた場合に、個体レベルの短波放射係数の差を求めた。

4/6研究×分類群（Utahワピチ・ミュールジカ、Wyomingミュールジカ・ビッグホーン）で太陽方向のタグペア係数が推定できた。Utahプロングホーン・ビッグホーンの同一タグ比較はN=0で**INSUFFICIENT_PAIRED_TAGS**。他の源平均をもって補間・代替しない。

元個体を2000回bootstrapした記述的・未補正95%区間が0を含まないもの：

| 原source | 軸 | コンテキスト順位2−順位1の係数差 | 元タグbootstrap95% |
|---|---|---:|---:|
| Utah ワピチ | q×日射残差 | **+0.010917** | [ +0.002570, +0.019078 ] |
| Wyoming ミュールジカ | q×日射残差 | **+0.006186** | [ +0.000227, +0.012687 ] |
| Wyoming ビッグホーン | sin方向×日射残差 | **+0.101212** | [ +0.066512, +0.136498 ] |

その他のペア軸は区間が0を含んだ。**順位2−順位1の順序は元GPSのq適格日・個体数の観測支持順位**で決まり、**高日射vs低日射**、季節後期vs初期、風の強弱ではない。したがって、上記の差を「日射量の増加によって動物が方向を変えた」と解釈できない。完全な環境依存性には同じタグの同じ季節・同一環境勾配に沿った明示的な移動機会・放射高度の制約が必要。

また、qは元個体・日ごとの夜昼GPS最短移動速度の対数差であり、真の活動時間割合でも個体が夜間に向く方向でもない。方向指標は太陽高度条件に合う昼間GPS移動区間のみを用いている。

## これからの生態学的な比較の優先順位

1. **GPS観測cadence**の昼夜・元study差がq／太陽方向の係数へ与える選別効果を、同じタグ・同じ適格日上の固定時間間隔の感度解析で検証。
2. 本来の元GPS地点と日射の**新しい物理数値版**を完全保存した契約に基づき、別元studies／別ギルドの真の原GPS条件付きモデルを分析する。異なる元studyの平均を同一個体効果としてプールしない。
3. 日射、温度、風、資源フェノロジー、移動様式が時間利用・移動方向の異質性を説明するかを、完全な元study単位の階層比較で評価する。**旧48原研究の外部負方向非再現**、以前の12元source生JSON版HOLDは不変。
