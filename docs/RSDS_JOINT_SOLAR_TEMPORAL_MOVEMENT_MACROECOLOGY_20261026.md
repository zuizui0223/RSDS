# RSDS — 太陽・季節・環境が組織化する時間ニッチと移動ニッチの一般性

**2026-10-26 / original public GPS and weather source results / exploratory cross-axis v0.**

## 中心質問

> 太陽・季節・環境の変化に対して、生物の時間利用と移動方向はどのように組織化され、その違いは種や地域を越えて一般化するのか？

この研究は論文の効果量を寄せ集めたメタ解析ではなく、公開原GPSデータ、原カメラ観測、ERA5、太陽位置の幾何計算から生成した **RSDS固有の生態学的比較データベース**を使う。時間利用、移動方向、日射量、気温、風、生物群をそれぞれ別個の結果として閉じずに、同じ原調査・同じ分類群・同じ季節条件で比較できる範囲を明示する。

## 状態と観測の分解

| 軸 | 状態・定義 | 何を意味しないか |
|---|---|---|
| 天文・季節 | 太陽方位 A、太陽高度 h、真太陽時 τ、日長 L、上昇/下降日長枝、年周期 | 気温・植生・雲量そのもの |
| 環境 | ERA5短波放射 R、気温 T、風流向/風速 W、水収支と植生フェノロジー | 個体が実際に受けた直達日射・木陰・体表温度 |
| 時間ニッチ（GPS） | 日中と夜間の同一個体における観測最短変位速度差 q=log1p(NIGHT速度)−log1p(DAY速度)、qとLの個体年内の傾き | 真の昼夜活動時間、休息か採食かの行動時間割合 |
| 時間ニッチ（カメラ） | 観測された撮影時刻分布、日中/夜間/薄明の区分 | 稼働と検出効率 q_det を補正した真の活動頻度 |
| 移動ニッチ | 原GPS移動方位 B、太陽相対方位差 B−A、cos(B−A)、sin(B−A)、観測移動速度 | 個体体軸の向き、太陽コンパス行動、太陽回避の因果性 |
| 一般性 | 同じ推定量が別の原調査・種・バイオームで再現するか。個体・原研究を区別する | 1原調査内の大量GPS点を独立地域の複数再現と数えること |

状態分布を記述するなら、条件をそろえた「時間軸」と「時間ごとの移動軸」の積に分解できる。

\[
P(\tau, V \mid E,g,s) =
P(\tau \mid E,g,s)\,
P(V \mid \tau,E,g,s)
\]

ここで E は天文・環境状態、g は原調査が確認した分類群、s は原GPS調査・地域、V はGPS移動方向と観測速度。これは確率分布の恒等的分解であって、両軸が統計的に独立することを意味しない。カメラの場合は潜在的な時間利用と装置稼働・検出確率を分けて観測過程を指定しないと、潜在 P(τ) を同定できない。

## 1. 同じ種の原GPS 2地域：時間利用と太陽相対移動方向の再現性は異なる

最も整合性の高い原調査比較は公開Movebank DOI **10.5441/001/1.711（Utah）** と **10.5441/001/1.703（Wyoming）**。同じ標本単位（原研究×原分類群）の結果に限定して、別々の解析で得た日長と昼夜相対GPS変位、および太陽相対移動方向を正確な**元論文の公開DOI＋学名**で結合する。研究内容は独立でも、異なる軸のGPS適格個体・年・ステップは一致するとは限らない。

| 原GPS研究・種 | 日長1時間増分に対する q の個体内傾き | 太陽相対移動平均 cos(B−A) | 観測上の含意 |
|---|---:|---:|---|
| Utah / ミュールジカ | **+0.005619** | **+0.023393** | q-日長正の傾き、太陽方向の生のcos正 |
| Wyoming / ミュールジカ | **+0.005538** | **−0.048758** | q-日長正の傾き、太陽方向の生のcos負 |
| Utah / ビッグホーン | −0.003412 | +0.020778 | q-日長の個体bootstrap区間は0を含む |
| Wyoming / ビッグホーン | +0.000217 | −0.005281 | q-日長と太陽方向の個体bootstrap区間は0を含む |

**観察的に肯定的な新しい複合結果：**
- ミュールジカの **q-日長の正の傾き**は別の2原調査で再び観測され、両調査の個体bootstrap95%区間は0より上にある。
- **同じ種の太陽相対移動の生方向平均はUtahで正、Wyomingで負**。この両調査の元の個体bootstrap95%区間は0を含まない。しかしこの差は移動経路の地理・個体サンプリングの変化と交絡するので「生態的な太陽反応が反転した」とは主張できない。
- 特にミュールジカの生方向平均差（Utah−Wyoming）は約 **+0.07215**。地理的方位marginalの差約+0.04589と、移動方向×太陽方位の結合成分差約+0.02626の**算術的和**である。前者は差の大部分を占めるが、これは因果的な寄与率・気象媒介率ではない。
- ミュールジカとビッグホーンの q（NIGHT−DAY最短GPS変位速度）の大小関係は各原調査でともにミュールジカ > ビッグホーン：Utah差 +0.04391、Wyoming差 +0.01551。しかし**Wyomingでは両種が共通に支えられた1°×年月セルが0**。これは原研究全体の分類群順位の反復であり、同所的なニッチ分割や競争とは区別する。

この組み合わせは、**種・地域をまたいで時間配分のある側面が似ていても、太陽に対する地理的移動方位は不変ではない**という、新しい比較研究仮説を支持する原データの記述的根拠になる。

## 2. より広い原GPSマクロ解析で、方位ニッチの再現性を確かめる

すでに保存された **40原GPSソース／41有効分類群コホート**から、正確に2アーカイブの原GPS結果がある**9学名**をすべて使う（都合の良い種だけを拾わない）。

- 太陽相対移動の生cos平均：**6/9学名で符号一致、3/9で不一致**。
- 原移動方位と太陽方位の結合成分（paired circular covariance）：**4/9で符号一致、5/9で不一致**。
- 時計補正後共分散は値が小さく符号も不安定であり、太陽方向へ向く進化的普遍則とは呼べない。

1原GPS研究の大量個体、複数年・複数分類群は独立な世界的再現数ではない。同じ分類群の2アーカイブにも標識個体・サンプリング範囲の重複があり得る。

## 3. 日射量が説明するか：いまの公開48ソースで何ができるか

原日射−太陽相対方向効果の公開GPS枠は、初期24原調査と外部24原調査、合計48原アーカイブ。各群10研究で個体内日射効果が推定可能で、**28原調査は未推定**であって生態的ゼロではない。

| 原調査群 | 日射100 W/m²増分に対する太陽相対方向 cos の平均傾き |
|---|---:|
| 初期10推定可能研究 | −0.019659 |
| 結果確認前に固定した外部10推定可能研究 | −0.003361 |

事前指定した外部の負方向再現判定は **NOT REPLICATED** で確定している。20ソースに後から気温・風と太陽の角度・粗い緯度・平均日射の順位勾配を当てると異質性が見えるが、**この48原調査と今回の日長−昼夜変位が推定可能なUtah/Wyoming原研究は、原DOIで重ならない**。既存の集計値から、気温や風が2種類のニッチの共分散を説明したと主張してはならない。

本当に新しい研究は、日長 q と日射方向効果を**同じ原GPSステップ／元個体／元地域**に再測定し、太陽高度・真太陽時・移動経路・風・季節条件で時間ニッチと方向ニッチの関係が残るかを検証すること。

## 4. 次に分離して検証すべき3つの環境機構

1. **天文幾何（幾何的ゼロ仮説）：** 太陽方位を変化する基準方向として使うだけで、地理的に固定された移動方位 B に cos(B−A) が生じる。真太陽時と太陽高度が混ざった結果を行動反応と呼ばない。
2. **気象・放射の条件付き変化：** ERA5短波放射のうち、元の太陽高度・細かい真太陽時・季節・元地域から予想される部分を差し引いた変動と、同一個体の時間配分・速度・cos/sin方位成分の関係を見る。雲量代理と日射の因果作用をさらに区別する。
3. **資源・移動様式の制約：** 環境の非同期性、風流向、植生、熱、移動回廊が時間ニッチ・移動方向ニッチを異なる階層で組織化しているか検証する。種・飛翔様式と原調査の構成を同じ係数に混同しない。

## 5. 検定上の重要な制約

- **再現の単位：** 元個体内での反復と、原研究・個体群をまたぐ反復は別。種間比較では独立生物群の数が不足しており、9種や2地域の符号一致数から系統一般化を結論しない。
- **同じGPSソース ≠ 同じ観測標本：** 日長 q の30〜120分間隔、太陽方位角、ERA5年×1°の変動、センサ間引きによって採用される個体と移動区間が異なる。生態学的デカップリングを個体内で実証するには元データを同じ適格条件で再解析する必要がある。
- **天文と時計：** 真太陽時、地方時、太陽高度と日長は互いに変換・相関するが完全に同一ではない。地球規模の季節平均だけでは非同期性を保持できない。
- **ERA5気象の履歴：** 既存の日長×気象共変量では再取得ERA5で値が変動した検証記録がある。凍結時の結果はそのまま保存し、新気象版での結果と勝手に統合しない。
- **カメラの観測過程：** 原撮影時刻分布と潜在的な生物の活動時刻は機器稼働と検出効率の影響を受ける。原GPS推定と計量単位が一致しないまま「共通時間ニッチ」としてプールしない。
- **非肯定的結果も残す：** Utahの厳密同日長・逆季節枝には適格個体年がゼロ、Wyomingの2種共通セルもゼロ、放射外部再現は不成立。原因探しのために選択基準を後からゆるめない。
