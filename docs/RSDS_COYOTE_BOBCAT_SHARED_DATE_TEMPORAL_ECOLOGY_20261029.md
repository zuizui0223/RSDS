# RSDS — 共存するコヨーテ・ボブキャットの時間ニッチは地域を越えて再現するか？

**2026-10-29｜原Movebank 2独立公表ソースの新しい昼夜GPS移動q・日長解析。原ソースは過去に太陽方位解析で開封済み、今回の時間応答は事後的・探索的。**

## 現在地と結論

Utah・Wyomingではミュールジカとビッグホーンの**昼夜相対GPS移動の種間順位**が2原研究・3観測時刻系列にわたり共通した一方、日長に対する種間傾きの符号は地域間で再現しなかった。そこで別の生態群（陸上食肉類）で、**同じ原研究内にいるコヨーテ (*Canis latrans*) とボブキャット (*Lynx rufus*)** の時間ニッチの相対順位・季節的日長応答を、イリノイ州とワシントン州の2公表原GPSソースに対して検証した。

**結果：イリノイ州で同じ194暦日のコヨーテの夜間相対GPS移動速度は、ボブキャットより大きい。ワシントン州は昼夜双方の元GPS速度差qを推定する条件を満たさず、2地域間の再現は未判定。** したがって元の有蹄類の2地域再現を肉食類へ拡張できたとは言えない。なお「夜間相対移動速度」が高いことは、夜間の活動時間・捕食回数・捕食成功率が高いことではない。

## Illinois：3 native taxaそれぞれの時間利用GPS指標

\(q=\log(1+\widetilde v_{\mathrm{night}})-\log(1+\widetilde v_{\mathrm{day}})\)。各 \(\widetilde v\) は元GPSをUTC1時間binごとに最大1記録選んだ後の、始点・中点・終点が同じ天文日付・昼夜区分に入る元GPS区間の**直線最短変位速度（km/h）**の中央値。動物の潜在的な「活動時間」ではない。

| native taxon | q適格元タグ | q（元タグbootstrap95%） | q~天文日長の係数/h（元タグbootstrap95%） |
|---|---:|---|---|
| *Canis latrans*（コヨーテ） | 20 | **+0.23604** [+0.17504,+0.29777] | +0.00347 [−0.02325,+0.02846]（16タグ） |
| *Lynx rufus*（ボブキャット） | 5 | **+0.09528** [+0.03700,+0.14769] | **−0.02825** [−0.03843,−0.01765]（5タグ） |
| *Odocoileus virginianus*（オジロジカ） | 23 | **+0.01474** [+0.00067,+0.02899] | −0.00162 [−0.00498,+0.00202]（23タグ） |

これらは**元の各taxon全適格日の研究内平均**であり、3種が完全に同じ日付で測られた値ではない。オジロジカをコヨーテと同じ暦日に対応づけた比較は今回の一次検定ではないため、「食肉類対被食者の時間ニッチ分割が実証された」とは結論しない。数字は原タグの**名目・未補正95%区間**であり、元タグが5個体しかないボブキャットの選択不確実性は大きい。

## Illinois：コヨーテとボブキャットが同じ年・暦日に観測されたとき

**新たな同所比較の肯定的結果：** 2種とも観測条件を満たす**194日・9年月ブロック**に対象を限定し、10日以上の有効日と43°Nを共通基準とした日長変動0.5時間以上を持つ元個体年だけを使用した。

| 指標 | 元GPS比較 |
|---|---|
| 同じ暦日を共有する元タグ（コヨーテ／ボブキャット） | **9／5** |
| q差：コヨーテ−ボブキャット | **+0.16552** |
| q差の原タグbootstrap95% | **[+0.06263,+0.26544]** |
| 個体年ごとのq~43°N共通日長傾きの種間差 | +0.04298/h |
| 種間日長傾き差の原タグbootstrap95% | **[−0.00091,+0.07961]（0を含む）** |

**同暦日のqレベル差は原タグbootstrap区間が0を含まず**、記録された夜間相対GPS変位速度の**順位**には同研究内の支持がある。一方、**日長応答の種間差**は分析単位に依存する。元タグを再標本化した種間傾き差はゼロを含み、年月ブロックを再標本化した同日平均との差の傾きは正でゼロを含まない。これらは同じ統計的推論対象ではなく、前者が支持不足なのに後者だけを理由に日長による種間可塑性を主張してはならない。

## Washington：元の昼夜適格条件が成立しない

Washington元研究の2種とも元GPSの正当な時間bin採用fixと原提供者MD5・先行原源解析は再現された。ただし元研究の**昼3本・夜3本の有効GPS区間を含む個体日と、個体年10日**という採用基準を満たす元個体は、コヨーテもボブキャットも**0**だった。元の太陽相対移動方向解析で用いたGPS情報は存在するが、夜昼速度差qや共観測日の日長係数には十分な計測機会がない。

結果は**UNAVAILABLE / 検証不能**であり、コヨーテとボブキャットの時間ニッチ差がWashingtonに「存在しない」、あるいはIllinoisの結果が「外部再現しなかった」ことを意味しない。元の偶数・奇数UTC時2時間系列でも、2研究内の2種の完全共通時刻条件を満たす群は成立しなかった。

## マクロ生態学上の解釈と次の検証

今回の同所の肉食類比較から、従来の有蹄類に続いて**昼夜GPS変位の種間順位が同じ公表原研究内で異なる**例が加わった。種間qの差が見えることは、**実際の採食・捕食・競争におけるニッチ分割の検証**とは異なる。また**別研究への一般化が、動物の行動差だけでなく元GPSの収録時刻・day/night双方のデータ機会の有無で制限される**と明確になった。

今後の最も実質的な生態学的な検証は、共存する複数種を別々のGPSスケジュールで計測した研究を無条件に統合するのでなく、**同じ原調査内で同暦日・同じ測位機会を持つ種間ペア**をさらに選び、別の地域でも種間qの相対順位と日長係数が再現するかを比較すること。次段階で日射、温度、風、緯度・移動経路を加えるには、新しいcanonical ERA5数値版で同じタグ時刻の比較を行う必要がある。

**過去の独立48原日射研究における負方向太陽方位効果の外部再現不成立と、旧ERA5の12原コンテキストのraw SHA版HOLDは不変。**
