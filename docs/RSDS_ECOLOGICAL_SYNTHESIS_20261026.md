# RSDS：太陽・日射・時刻・季節の肯定的結果と主張の境界

**資料固定：2026-10-26。移転元 ODSP commit d58fb759416fc458f69ef61ea79b7b1d4164f2c5。**
本研究は原Movebank GPS、公開カメラ観測、ERA5、衛星由来環境データを用いた原データ解析であり、過去の論文に書かれた効果量を単純統合したメタ解析ではない。以下は支持された観測結果と、それとは区別する未検証の因果説明を整理する。

## A. 同じ日長でも、季節により昼夜変位は一様に変わらない

- 公開GPSの10原ソースコホート・254適格動物個体で、相対夜側GPS変位の枝間差は正・負・小効果に分かれた。ワピチ +0.045、ミュールジカ +0.031、クロクマ −0.077、Etoshaゾウ −0.150、Krugerゾウ −0.0289などは**個別原調査の値**であり、一般集団平均ではない。
- ミュールジカでは独立したUtahとWyoming原GPS調査に、日長に対する相対夜側GPS変位の年内係数 +0.00562 と +0.00554 が見つかった。ビッグホーンは対応する傾きが弱い／不確実である。因果的な日長感受性を直接測ってはいない。
- Etoshaゾウでは2009・2010の両方の年で負の昼夜相対変位が再現した。ただし同じ地域のジャッカルが確実に逆方向であるという主張は年別分割後に支持が弱まり、保留する。歴史的GPS固定間隔 v0 と時刻基準の間引き v1 は異なる推定対象として保持する。
- 詳細：[複数動物種の太陽暦](solar_calendar_multispecies_ecological_results_20261019.md)、[2調査によるミュールジカとビッグホーン](odsp_ungulates_two_independent_source_20261022.md)、[原Movebankの最初の季節GPS結果](movebank_first_biological_seasonal_gps_results_20261019.md)。

## B. 天文日長は、季節の温度・水分状態を完全には表さない

- 固定した21陸域点×3年でERA5等日長ペアのうち62/63が物理的に有効。29/62ペアでは温度と浅い土壌水分の下降枝−上昇枝の符号が逆である。
- 年別の温度と水分の反対方向が複数年平均に隠れる例があり、季節平均だけを用いると環境変化の順序・非同期性を失う。21点は代表的な全球面積標本ではなく、ERA5は直接計測値でもない。
- 詳細：[21固定陸域地点のERA5結果](global_equinoctial_ERA5_21land_sites_2018_2020_ecological_results.md)、[気候履歴の比較](global_fixed_21sites_ERA5_multiday_environment_history_20261019.md)。

## C. 太陽方位相対の移動と日射量：存在する異質性をマクロ生態学の中心とする

- 動物のGPS移動方位 B と瞬間の太陽方位 A に対して Y=cos(B−A) と定義する。正・負の値は観測された移動方位分布を表すが、太陽利用や忌避の直接証明ではない。公開原GPSの40ソース・41分類群コホートに方向分布の異質性が記録されている。
- 最初の24ソースのうち10研究で、同じ個体内の月×4時間真太陽時条件でERA5短波放射100 W/m²増加に対するY係数のソース均等平均は −0.01966。その初期群では個別ソースcluster bootstrapの記述的95%区間が負だった。
- **別途結果確認前に固定した外部24ソース**のうち推定可能な10ソースは平均 −0.00336であり、事前定義した負方向の外部再現基準を満たさなかった。前の値を削除したり「全世界で動物は日射を避ける」と解釈しない。
- 全48ソース中28は日射係数が未推定でありゼロとはしない。20有効ソースの後付け探索的順位相関は、原調査で経験した気温 +0.448、風流向と太陽方向の一致度 +0.499、15°緯度帯近似 −0.564、平均日射量 +0.075。原研究の非ランダムな分類群・経路・気候をまたぐ集計パターンであり、個体内の因果効果ではない。
- 14個の同種・同ソース2環境ペア（12原研究）では、高日射環境−低日射環境における日射係数差はソース均等平均 −0.00756、正7原研究／負5で、単調な生物学的関係は確定できない。
- 未検証で次に進める中心質問は**真太陽高度・細かい太陽時刻・移動経路・風を条件づけても、雲量等による日射変動と個体内方向分布に関連が残るか**である。発見済みのマクロ異質性と、原因の同定を分ける。
- 詳細：[原GPSと日射の外部再現失敗](solar_radiation_two_24_source_nonreplication_ecology_20261025.md)、[新しい48ソースのマクロ環境勾配](solar_irradiance_direction_macroecology_20261026.md)、[風と日射の原GPS比較](solar_wind_irradiance_original_GPS_ecological_results_20261025.md)、[全球太陽方位原GPS結果](global_solar_azimuth_macroecology_20261025.md)。

## D. 原カメラの撮影時刻と生物学的時計は別の対象

- Serengetiや北アイルランドの記録では、ほぼ同日長に対する増加／減少日長枝で写真が記録された時刻分布や昼光縁・夜間の記録再配置が分類群によって異なる。
- カメラ稼働時間・位置選択・検出感度 q と同じ原母集団の確保が不十分なため、真の動物活動量や時計記憶の進化に読み替えない。
- 詳細：[元画像の季節分配](solar_seasonal_real_exploratory_results_20261015.md)、[撮影日とERA5の日周結合](serengeti_actual_solar_photo_era5_cycle_joint_result_20261015.md)、[撮影機と時刻構成の分離](serengeti_within_photo_time_versus_station_mix_ecology_20261015.md)。

## E. 独立原調査での「時間ニッチは反復するが、生の太陽方向は変わる」対照（2026-10-26）

RSDSでUtah DOI 10.5441/001/1.711とWyoming DOI 10.5441/001/1.703の学名・元調査DOIを厳密に結合し、原GPSの **6 study×taxon記述行**を実計算した。個体の昼夜GPS最短変位速度差 q に対する日長の年内傾きは、ミュールジカで **+0.005619（Utah）、+0.005538（Wyoming）**と双方正で、それぞれの原ソース個体bootstrap区間は0を含まない。しかし瞬間太陽方位に対する移動方位の**生cos平均**は **+0.023393** と **−0.048758**で、原ソース個体bootstrap区間は逆符号を支持する。この差 **+0.072151** は地理的方位marginal差 **+0.045886** と結合成分差 **+0.026265** の算術的和であり、太陽反応や気候媒介率を同定したものではない。

ビッグホーンのq-日長係数は両原調査で不確実。夜−昼相対変位のミュールジカ＞ビッグホーンという順位は両調査で繰り返されたが、Wyomingには両種共通の適格1°セル×年月が**0**なので、同所競争やニッチ分割の再現性とは区別する。さらに、9学名×各2原GPSアーカイブの太陽相対方向の生符号一致は **6/9**、地理的方位を分離したjoint covariance符号一致は **4/9**。生の太陽相対方向がすべての地域で保たれるとは言えない。

48原GPS日射研究のうち20のみ放射傾き推定可能。時間利用を推定したUtah/Wyomingの原2研究と48原日射研究で元DOIの共通性が**ゼロ**なので、いまの別研究間の集計値から個体内「日射が時間配分と方向を媒介する」という関係を作り出さない。新規の正面検証は**同じ個体・移動ステップで真太陽高度、細かい太陽時刻、風、放射、経路と昼夜配分を同時解析すること**である。

## F. 同一GPS個体で時間・移動方向・時別日射を結合した初回実データ結果（2026-10-26）

これまでの原データ研究では、「時間ニッチのq−日長係数」と「太陽相対方位の平均」が同じ2原調査で計量可能になった一方、旧48原調査のERA5日射傾きと元Utah・Wyomingの時間利用結果に原調査DOIの重なりがなかった。その問題を解くため、元Utah（4分類群）とWyoming（2分類群）の**同一標識個体と観測日**について、GPS夜昼最短変位 q・GPS昼間の太陽相対cos/sin方位・ERA5時別日射/風/気温を実際に一つの解析系で計量した。両原GPSの元プロバイダMD5と全6分類群の以前のq・日長傾き・元タグ数は**新しいERA5アクセス以前**にすべて完全再現した。

元個体計数と元昼夜変位の日数のみで各分類群から上位2つの元1°グリッド年を選び（計12分類群×環境コンテキスト、重複除去したERA5取得は10元グリッド年）、すべての適格GPS昼間移動ステップに完全なERA5時刻リンクが成立した。天文太陽高度（1次・2次）、瞬間太陽方位、1時間幅の真太陽時計時刻×月、天文日長、2m気温、100m風速、風と太陽の相対方向をモデルで条件づけた。方向と昼夜相対変位の両方の新しい個体内・条件付き傾きを推定できた元タグ個体は、Utahプロングホーン99、ワピチ89、ミュールジカ84、ビッグホーン85、Wyomingミュールジカ54、ビッグホーン23の**合計434**である。これは434独立な地域・生態系ではない。

- **全6分類群で、昼夜相対GPS変位 q と残差日射量との係数の個体単位bootstrap95%区間は0を含んだ。** 「日長で見えていた移動の季節係数」が一律に「日射量の直接効果」であるという単純な説明は支持されなかった。ただし気象効果ゼロを示すものでもない。
- **Utahビッグホーンに特異的な肯定的な観測的関連：** 移動方向の太陽相対cos成分に対する+100 W/m²残差日射係数 **+0.01686**（元タグbootstrap95% **+0.00636〜+0.02647**）、sin成分 **+0.02917**（**+0.01765〜+0.04126**）。2成分の正の元調査条件付き関連は、事後選択した複数群・軸の一つであり、家族内多重比較を調整した新しい種一般の肯定的検定ではない。
- **Wyomingの同種では同じ源元調査全体のcosとsinの区間はいずれも0を含む。** しかし選択済み2グリッド年のsin係数は**−0.06470 [−0.09735,−0.03217]** と **+0.03686 [+0.02385,+0.05022]** で正負が反転した。原個体の両コンテキストでの対応、元移動経路、年・採食環境・気象の違いを完全一致させていないため、局所環境が反応を因果的に逆転させたと断定しない。
- 旧48原GPS日射調査の**外部負方向再現不成立**はそのまま残す。今回のUtah/Wyomingの条件付き推定は違う標本・推定量なので、旧判定を復活・取り消ししない。

したがって一つの統合生態学的問いは、**時間利用の天文日長に関する相対的な共通性と、太陽方向・気象変動に関する局所的な異質性がなぜ共存するのか**である。次の核心的な原データ検証は、同じ元タグが2つの選択元グリッド年の双方を測っている部分集合に限定した、個体対応付きの環境・方向傾き差と、まったく新しい原GPS調査の独立な移動ギルド・地域での反復である。
