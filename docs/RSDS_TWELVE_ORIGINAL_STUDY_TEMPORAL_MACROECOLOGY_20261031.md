# RSDS：12原調査のGPS時間ニッチと日長応答は、独立研究単位でどう一般化するか

**2026年10月31日｜公表Movebank原研究12件／22研究×分類群行／登録学名20。source-equalマクロ生態学 v1（事後統合）。**

## 主目標と確定した結果

太陽・季節・気象条件の下での動物の時間利用と方向利用を比較する際、元GPS観測点数、標識個体数、原研究内の分類群数をそのまま「独立した生態系」と見なすことはできない。これまでのRSDSで確認済みの元8研究・12 native source×taxon行を、2026年10月29日に初回原GPS結果が固定された**別の4公表研究・10登録分類群**と統合し、**計12研究・22研究×分類群・20学名**を同じ研究単位で数えた。

この統合は、新しいGPSを取得・再フィットする分析ではない。以前の**MD5検証済み原ソースの第一次結果**（8研究／新4研究／新4研究の分類群と共通カレンダー検証／元ファイルメタデータ）のGit blob SHAをすべて検証し、元のHOLDや旧の外部再現不成立を保持した。前の動物の結果を見た後の事後統合であり、確証的な地球全体の統計推定でも、無作為な世界生態系標本でもない。

qの定義は元の研究を通じて、対象個体の観測GPS記録における **log(1+夜間の中央値直線変位速度 km/h) − log(1+昼間の中央値直線変位速度 km/h)**。これは真の活動時間割合ではない。日長係数は、同一元個体の元年内でqを天文日長で回帰した観測的傾きである。雲による日射、温度、風、繁殖季節などの因果効果を直接測っていない。

## 原調査を1単位にした結果

元研究の中で推定可能なnative taxonの係数を均等平均し、そのあと**元DOIに各1票**を与える。元研究の動物個体数が何千件あっても、同じ研究をそれだけ独立生態系と数えない。容量・taxon schema・GPS cadenceで未推定の元studyは一切ゼロ化しない。

| 指標・方法 | 既存8元study | 拡張後12元study |
|---|---:|---:|
| q推定可能元study | 7/8 | **9/12** |
| 元study×taxon行をそのまま均等に平均したq | **+0.004797** | **−0.022510** |
| **元DOI均等のq平均** | **+0.034640** | **+0.010262** |
| 元DOI均等のqの記述的bootstrap95% | −0.03414〜+0.10346 | **−0.04923〜+0.07674** |
| 元DOI均等の元q平均の符号 | 正4・負3 | **正4・負5** |

拡張後の**9研究均等q平均 +0.010262**は、推定可能な1元研究を1つずつ除外すると **−0.012174〜+0.026563**まで動き、ゼロをまたぐ。これに対し15 source×taxon行を均等平均すると **−0.022510**になる。分類群行の多いUtahや新ガン類1原studyの重みが違うためであり、「動物全体の普遍的な夜／昼優勢」という結論はこの原研究標本では成立しない。

元DOI均等の**q~天文日長傾き**も約 **−0.00638/h**（研究ブロックbootstrap95% −0.01880〜+0.00340）で区間は0を含む。元研究DOI均等の日長係数点推定の符号は正5・負4。元個体内年の傾きは種ごと・場所ごとの季節的変化を反映し得るが、物理的な日長が動物の活動を直接制御した効果ではない。

## 新しい生態学的補助証拠：ガン3種は同じ120暦日でも日長関連が違う

新しいガン原研究 **DOI 10.5441/001/1.fk899541** では、登録された3学名について全種に共通する**120暦日、5つの年×月ブロック**が成立した。以下は元動物の**同じ元調査カレンダーを共有した特別な別の推論対象**であり、上記「元全studyの日長係数」とは混ぜない。

| ガン3種の学名 | 共通暦日でのq | 共通研究参照日長1hあたりqの係数 |
|---|---:|---:|
| *Branta leucopsis*（カオジロガン） | −0.18403 | **−0.02171** |
| *Anser albifrons*（マガン） | −0.08391 | −0.01581（元個体区間は0を含む） |
| *Anser anser*（ハイイロガン） | −0.06918 | **+0.02066** |

すべての種で記録されたGPS移動は昼間相対優勢だったが、**時間ニッチの位置（qの絶対値）と、日長に沿った時間利用の変化（傾き）は同じではない**ことが、元同一研究・同一暦日上で示された。全3組のq差・日長関連も元研究の[第一次結果](../research/RSDS_FOUR_NEW_MULTINATIVE_GPS_SHARED_CALENDAR_V1_FIRST_RESULT_20261029.json)と独立した[科学的検証](../research/RSDS_FOUR_MULTINATIVE_ORIGINAL_GPS_ECOLOGICAL_VALIDATION_V1_20261029.json)で保存されている。

マガン−ハイイロガンの日長関連差は、暦月内で基準日長変化を中心化した事後解析でも **−0.03594/h**、月ブロックbootstrap95% **[−0.11046,−0.00392]** と負。しかし**5年月ブロック・3組の事後比較・同じ元研究内**という制約から、太陽の光刺激・種間競争の因果機構や独立した地球規模の再現性を証明しない。

## 失敗・保留を結果に残す

- **ダイサギ（1 native行）**：元原GPSファイルが事前200MBサイズ上限を超え、解析のために別ファイルへ置換していない。
- **ガラパゴスゾウガメ（3 native行）**：元公開GPSファイルMD5は一致したが、元CSVの厳密学名ラベルと登録学名の対応が取れずnative qが計算不能。これは動物がいない証拠ではなくtaxon schema問題。
- **アフリカハゲワシ（2 native行）**：元の昼3・夜3 GPS区間と10日支持の閾値を満たす動物が不足。
- **渡りガモ *Anas acuta*（1 native行）**：元のq適格動物0。マガモだけで源study qを計算できるが、2種の同一暦日差は未推定。

**計7行の未推定は、q=0でも生態学的な効果の否定でもない。** 本解析では未推定元studyも12元DOIの分母に残す。

## 生態学的結論と今後の境界

この研究の現在の肯定的な発見は、**観測された昼夜GPS移動ニッチは複数の公開元研究をまたいで非一様であり、天文日長との観測的関連もすべての分類群で同一符号にはならない**こと。そして**同じ暦日に複数種を比較すると、時間ニッチの位置と日長に沿う変化方向を区別できる**ことだ。

まだ同定されていないのは、真の活動時間予算、日射量・気温・風による原因的な応答、太陽コンパスの利用、同所種間競争や繁殖状態による媒介、世界の系統群集への代表的な外挿である。元のGPS取得間隔とUTC時刻位相も分類群・調査間で異なり、測位時刻を完全に揃えたqでは元個体数が大きく減る原studyもある。

旧48原studyにおける短波放射→太陽相対移動の外部負方向再現失敗、およびERA5旧JSON SHA12コンテキスト保留は維持。**この12研究統合はGPSの移動と天文日長に限られ、ERA5の旧短波放射効果を再確認した結果ではない。**
