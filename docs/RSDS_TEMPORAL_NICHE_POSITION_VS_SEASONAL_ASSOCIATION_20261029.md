# RSDS：時間ニッチの「位置」と「季節変化の方向」は別の生態学的軸

**2026-10-29 / 二つの公表元GPS調査：IllinoisとWyoming / 結果を事後的に整理した生態学的仮説**

## 原研究で直接支持された比較

RSDSの中心質問は、太陽・季節・環境に対する生物の時間利用と移動方向の組織化が、どこまで種や地域を超えて一般化するかである。ここまでの原Movebank GPSから見える、**マクロ生態学的に検証する価値があるパターン**は、日周移動の「基準位置」とその「季節に沿った勾配」が、必ずしも同じ向きではないことである。

下表は、**各元研究で実際に複数種が観測された同じ暦日**に限った記述的な元個体値である。各元研究の範囲で元標識個体を2000回bootstrapした名目95%区間を使用し、多重検定や世界標本の補正はまだしていない。

- Wyoming：ミュールジカ − ビッグホーンのq差は +0.01702 [0.01416,0.01987]、日長係数差は +0.01235 [0.00982,0.01496]。同じ原研究193暦日、元時刻・UTC偶数・奇数の3 GPSサンプリング系列で種間順序と傾き差を別途確認している。

## 科学的に一段深い問い

**同じ場所・季節を共有しても、日周移動ニッチの基準位置が似た分類群が、季節的な環境変化に対して異なる方向へ移動を再配分することはあるか？**

この問いは単純な「昼行性と夜行性を分ける」だけでは答えられない。時間ニッチを少なくとも次の別々の記述軸で捉える。

1. **位置（position）：** q。夜−昼の観測GPS直線変位速度の相対差であって、真の活動時間割合・餌探索時間・昼夜の消費エネルギーではない。
2. **季節反応の勾配（seasonal association）：** qと天文日長の元個体年内傾き。ただし天文日長は日付そのものの決定関数で、温度・餌・生殖状態・移動場所・測位機器の季節差と共変動する。
3. **太陽に対する移動方位（direction）：** \(\cos(B-A)\)、\(\sin(B-A)\)と地理的移動方位のmarginal／joint circular covarianceは別の推論対象。前2軸の符号から太陽コンパスや日射回避を予言しない。

ここでの「独立した軸」は**測定上・科学的に区別すべき軸**という意味であって、統計的に独立・原因的に独立という結論ではない。

## 今回進行中の焦点：日長そのものか、月をまたぐ季節の違いか

[Illinois＋Wyomingの事後的な暦月内条件付き原GPS検証](../research/RSDS_SHARED_MONTH_ADJUSTED_PHOTOPERIOD_SOURCE_V1_CONTRACT.json)では、もともとの共通169日／193日と元個体群は変えず、同じ**年月ブロック**内でLと種間q差の平均をそれぞれ引いてから傾きを再推定する。元の全期間の日長係数は事前に1e−12以内で数値再現を要求する。

この比較で仮に日長係数が弱まれば、「以前の結果が年内の月間差を強く反映していた」と記述できるが、日長因果仮説を否定したとまでは言えない。逆に暦月内でも元タグ／月ブロック区間が同じ符号を示しても、**同じ月の中で天文日長は日付とほぼ一対一に対応する**ため、餌・体調・季節的移動などから光周期作用を識別したわけではない。元9/8年月ブロックしかないため、結論は探索的・研究内条件付きに限る。

## 結論と今後の一般化

現時点で肯定的に支持されるのは、**Illinoisの2肉食類とWyomingの2有蹄類という2つの原研究内で、相対昼夜GPS変位qの位置と日長との季節的関連が同じ単一符号へ縮約されない**という現象である。原因は未同定。次の検証では、複数種が実際に同じ場所と日付で観測された**別の独立元GPS研究**へ同じ計測を固定して移すことが重要。単にタグ数を増やしても独立な研究・地域・分類群数は増えない。

48原GPS研究の日射−移動方位の事前指定外部再現失敗、旧ERA5の12元応答JSON SHAバージョンHOLDを更新しない。原GPSの個体ID、正確な元日時・位置・個体別係数を再配布しない。
