# RSDS — 同じ2種で、日周移動の順位は再現するが、日長応答の種間差は地域で異なる

**2026年10月29日｜独立した2つの公表Movebank原研究｜同一原研究内の共通観測日とGPS測位スケジュールを照合した観測的比較**

## 現在地と科学的な問い

Wyomingの1公表原GPS調査（DOI 10.5441/001/1.703）では、ミュールジカ *Odocoileus hemionus* とビッグホーン *Ovis canadensis* の観測暦日を揃えても、観測NIGHT−DAY GPS移動速度差qと天文日長の傾きがそれぞれ正／負だった。そこで、**元の独立したUtah調査（DOI 10.5441/001/1.711）でも同じ2種・同じ基準天文日長43°N・同じ3測位時刻系列で成立するか**を検証した。

これはWyomingの正負対照を**見たあとに**対象種を固定した追加原研究検証であり、未開封のブラインドな事前登録仮説テストではない。元Utah調査の4分類群すべての元GPSファイルUUID／バイト数／MD5、以前の元個体qとq〜日長係数を新しい種間比較の前に再現した。以前の原GPS 3系列のqと日長傾きも、比較対象2種について1e−12以内で再現できた。

## データ支持を固定してから比較した内容

- 元の「1時間UTC binごとに最大1 GPS fixを採用した系列」と、元のUTC偶数時だけ・奇数時だけの2時間GPS系列の3つを使用。元の各GPS区間は実際の直線移動を測り、どの系列も実活動時間の真値を直接測っていない。
- 元study内で**両種に少なくとも1個体ずつ3系列の昼夜移動判定に適格なGPS記録のある同じ暦日**だけを抽出する。共通暦日に10日以上・43°N基準日長の幅が0.5時間以上ある元個体年を選び、元study内で日数支持が一致するまで反復する。**日長係数の符号やq値で日付を選ばない。**
- 各元タグの同一年内でq〜43°Nの天文日長傾きを計算し、元タグを単位とする2000回の未補正bootstrap区間を算出。さらに同じ暦日の2種別平均qを差し引いて、その日差を日長で回帰する*暦日単位*の別解析を年月ブロックで再標本化した。
- 2種の元タグとマイクロハビタットを同一視しない。共通暦日が193／199日あっても、すべての元タグがすべての日に観測されたわけではない。元studyはそれぞれ**1独立フィールド研究単位**である。

## 結果1：同じ季節の2種でも日長応答が反対という現象はWyoming固有の可能性

<text color="secondary" size="sm">qは夜間−昼間のGPS直線変位速度のlog1p差。日長係数は日長が1時間増えるときのq変化の観測的関連。</text>

| 元source条件 | Wyoming | Utah |
|---|---:|---:|
| 2種がともに観測された共通暦日 | **193日** | **199日** |
| 共通暦日を10日以上持つ元タグ（ミュールジカ） | **108** | **10** |
| 同（ビッグホーン） | **41** | **42** |
| 2種の共通年／年月ブロック | 2年／8ブロック | 2年／10ブロック |
| 元GPS q〜日長：ミュールジカ | **+0.00783** | **+0.01374** |
| 元GPS q〜日長：ビッグホーン | **−0.00452** | **+0.04094** |
| 元GPSの傾き差（ミュール−ビッグホーン） | **+0.01235** | −0.02720 |
| 元タグbootstrap95%（種間差） | **[+0.00982,+0.01496]** | **[−0.07008,+0.01320]** |
| 同日・元studyでの2種平均q差〜日長 | **+0.01167** | −0.000055 |
| 同日・年月ブロックbootstrap95% | **[+0.00763,+0.02029]** | **[−0.00956,+0.01514]** |

**Wyoming：** 193共通暦日の条件でも2種の元タグのq〜日長係数はそれぞれ正・負で、種間差の元タグbootstrap95%区間は正。さらに日付ごとの平均qの差を用いた年月ブロックの記述的区間も正。

**Utah：** 199共通暦日の条件でミュールジカの元タグq〜日長係数は正（元タグbootstrap95% [+0.00101,+0.03343]）だが、ビッグホーンも正（[+0.00426,+0.08339]）。**種間差の区間は0を含む**。同じ日付単位の平均との差に対する日長傾きも区間が0を含む。UtahではWyomingの「ミュール正・ビッグホーン負」という組合せを支持できない。

奇数UTC時だけの2時間GPS系列では、Utahの両種とも日長傾きの区間が0を含み、測位位相に対する支持の弱さも残る。Utahは元のGPS点が奇数UTC時へ集中する原調査で、対象ミュールジカ10タグにしか共通日付条件を満たす支持がなく、**Wyomingで確認したパターンがUtahで不存在だとは言えない**。

## 結果2：季節的な傾きと異なり、日周相対移動の種間順位は2原研究で共通

同一studyの共通日付での**qレベルの差**（ミュールジカ−ビッグホーン）を見ると：

| GPS測位スケジュール | Wyomingのq種間差 [95%区間] | Utahのq種間差 [95%区間] |
|---|---|---|
| 元UTC 1時間bin系列 | **+0.01702 [0.01416,0.01987]** | **+0.03767 [0.02158,0.05716]** |
| UTC偶数時だけ | **+0.01464 [0.01125,0.01798]** | **+0.04253 [0.02614,0.06142]** |
| UTC奇数時だけ | **+0.02339 [0.02032,0.02665]** | **+0.03490 [0.01839,0.05346]** |

6つすべての元タグbootstrap95%区間は0より大きい。**2つの独立した公表調査において、同じ暦日内のミュールジカのqがビッグホーンより相対的に高い**。これは平均的な日周の**観測GPS移動の種間順位**が、2つの研究と3種類の測位時刻系列にわたって共通だったという観測的な再現である。

ただしqが正になる種間差は、ミュールジカが必ず夜行性であるという意味ではない。両種がq負でも、ミュールジカの負の値が小さければこの差は正になる。元の動物の「真の活動時間」「採食時間」「夜間活動割合」ではなく、**GPS直線移動速度の夜−昼の対数差の種間順位**に限った知見である。

## 生態学的な主要示唆

**時間ニッチの相対的な位置（平均的な昼夜GPS移動配分）は2地域の同じ2種で同方向を示す一方、季節的な天文日長との関係の種間差は共通しなかった。** これは生物種の時間利用を1つの「昼行・夜行」スカラーに押し込まず、少なくとも**日周の相対的な位置と季節変化の係数を別の生態学的軸**として扱うべき理由になる。

しかしこの比較はUtah・Wyomingの計2独立原研究であり、動物のGPS機種・時間間隔・地形・実際に受けた日射・気温・風・資源・移動経路・個体群史を制御していない。Utahの10ミュールジカというデータ支持の小ささと、多重比較未補正の記述的95%区間を保持する。**日長がこれらの違いを引き起こした、環境による種間可塑性が示された、世界一般則として日周順位が保存される**とは主張しない。特に、Utahの2種を選んだのはWyomingの先行結果を見たあとであり、ブラインドな外部確認ではない。

新しいRSDSの次の原データ検証では、**複数の独立した調査から観測努力・測位cadenceを統一し、日長・日射・気温・風と日周qの生態学的関連を分離**する必要がある。元ODSPからの短波放射48原研究での事前指定負方向外部再現不成立、ERA5旧raw JSONの12ソースHOLDはそのまま。
