## 正の生態学的解釈と未支持の機構

「天文時計に対する移動方向」と「日中/夜間の相対GPS変位」は単一の普遍的な光感受性ではない可能性がある。既存8原studyの時間/移動方向マクロアトラスに、同一個体・同じ採用日で太陽の高度・方位・真太陽時・風・温度を考慮した**2原研究の環境関連の再解析**が接続できた。ただし世界の分類群や地域から無作為に抽出した実験でなく、同じ個体が異なる観測コンテキストに現れても観測環境そのものは未制御である。

現状、**全種共通の放射回避、太陽コンパス利用、日長記憶、世界的な気象媒介効果**はいずれも支持・同定されていない。別系の48元研究の日射−移動方位効果の事前固定外部再現失敗は上書きしない。
