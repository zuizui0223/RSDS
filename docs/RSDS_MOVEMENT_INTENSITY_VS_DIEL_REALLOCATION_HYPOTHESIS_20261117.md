# RSDSの生態学的な次の問い：気温によって変わるのは「総移動強度」か「昼夜への配分」か

**2026-11-17。** 3原研究のミュールジカの正の気温–夜間相対移動から、有蹄類の種間比較に接続する**仮説・概念整理**。これ自体は新たな有意差検定や動物の因果的行動実証ではない。

## 1. 指標を分ける理由

同じ個体・同じソーラー日の GPS 有効移動区間から

```
D = log(1 + median accepted DAY GPS step speed)
N = log(1 + median accepted NIGHT GPS step speed)
Q = N − D              相対的な夜間変位の偏り
I = (N + D) / 2        昼夜速度成分の平均（観測変位の強度）
```

と分ける。気温Tmaxの元同一年・同月内の条件付き回帰でも、**`β_Q=β_N−β_D`、`β_I=(β_N+β_D)/2`** が成り立つ。さらに `β_N=β_I+β_Q/2`、`β_D=β_I−β_Q/2`。したがって、`Q` が変わらなくても昼夜の速度の双方が増えることがあり、逆に全体の速度強度が大きく変わらなくても昼夜配分が変わり得る。

`I` は真の生理的活動量／エネルギー消費量でない。GPS の**観測された直線変位速度成分**の平均に限定して解釈する。

## 2. 元公開GPSデータによる現時点の対比

以前確定したミュールジカの3原研究（Utah, Wyoming, Sublette）では、夜間の `β_N` は3/3で名目95%個体bootstrap区間が正。昼夜各3有効GPS区間に固定しても3/3で正、日中の `β_D` はSubletteで負、Utahと旧Wyomingは不確定だった。これまでの `Q` の正符号とともに、気温関連の「夜間側」への偏りが最も再現的だった。

さらに [PR #45](https://github.com/zuizui0223/RSDS/pull/45) の**Wyoming原GPS 2種**を同じ暦年×月内・日長・先行30日水収支調整で解析した最初の結果では：

| 元Wyoming原研究、同じ統計モデル | 元標識個体 | DAY `β_D` | NIGHT `β_N` | Q `β_Q` |
|---|---:|---:|---:|---:|
| ミュールジカ *O. hemionus* | 109 | +0.000165（不確定） | **+0.000736** | **+0.000571** |
| ビッグホーン *O. canadensis* | 41 | **+0.000476** | **+0.000501** | +0.000025（不確定） |

ビッグホーンの結果は「両時間帯で元GPS速度と高温が正に関連する場合でも、`Q` はほぼ変わらない」という**強度変化と昼夜配分変化の非同値性**を示す実例に近い。ただし `β_I` をまだ対応tag-bootstrapで正式に推定していないので、`I` の有意性をこの表から主張しない。ミュールジカの観測上の夜間偏りも、実際の夜行性／摂餌／熱調節の証明ではない。

**重要な測定結果：このWyoming原研究のミュールジカとビッグホーンは、元のq適格GPS観測に共通の1°格子×年月が0件だった。** 研究アーカイブが同じでも生息地・観測季節を共有する比較ではなく、上の数値を種の固有的な「熱適応差」の実証と解釈できない。

## 3. 今回の元Utah全4種の結果で検証すること

Utahの *Antilocapra americana*, *Cervus elaphus*, *Odocoileus hemionus*, *Ovis canadensis*、Wyomingのミュールジカとビッグホーンを**一種も省かず6行**として解析する。気温の観測上の関連は、ソース内同一年・同月の DAY と NIGHT の二成分それぞれとその差で記録する。元のqおよび天文日長係数、原公開ファイルMD5、同一研究におけるERA5物理版の整合性を先に監査する。Utahの旧日別気象解析で見えた「ミュールジカ正・ビッグホーン負」は、年月内・同じERA5提供時点で残るかまだ未確定。

Utah原研究内の**共通1°格子×年月の機会数**も先に算出し、将来の真の種×温度差の検定に必要な共有環境条件が存在するか確認する。元の旧Utah共通格子×年月解析では、気温＋日長＋水収支を同時に調整したミュールジカ−ビッグホーンの温度係数は名目区間がゼロを含んだ。前後で統計モデルやERA5物理版が異なるため、この結果と新6行の係数を無批判に合算しない。

## 4. 生態学的な主張の候補と不確実性

現時点で許される問いは：

> **高温時に観測される動物のGPS移動は、単なる昼夜共通の強度増加か、それとも夜間と日中の速度差の再配分を含むのか。どの条件で種や集団による異質性が生じるか。**

ここから「有蹄類は一律に夜行性になる」や「暑熱回避は種に固有である」と一般化しない。これらの原研究は少数かつ選択済みで、生息地・繁殖状態・測位スケジュール・捕食者・温熱曝露は対照化されていない。強い因果メカニズムの主張には元GPSで把握できない活動・行動状態も必要。
