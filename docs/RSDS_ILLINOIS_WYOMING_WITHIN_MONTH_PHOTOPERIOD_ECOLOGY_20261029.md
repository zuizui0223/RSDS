# RSDS：同じ暦月内でも、共存種の時間ニッチと日長の関係は異なるか？

**2026-10-29｜Movebank元Illinois（コヨーテ・ボブキャット・オジロジカ）とWyoming（ミュールジカ・ビッグホーン）の同暦日検証｜事後的な探索解析**

## 今回確定した結果

元Illinois研究（DOI 10.5441/001/1.649）の169種間共通暦日と、元Wyoming研究（DOI 10.5441/001/1.703）の193共通暦日を、過去に保存した原研究と同じ元GPS原ファイルMD5、元採用個体・qとq~日長係数、同暦日支持から完全再現した。

両研究の共通日について、天文日長を**43°Nに固定した参照値**で評価し、年月ブロックのq種間差と日長の平均との差を除去してから、**暦月内の変化だけ**を使ってq種間差~日長係数を再計算した。2000回の年月ブロック再標本化の記述的95%区間を計算し、ひとつの暦月を除いた係数範囲も保持。これは暦月間の季節的変動を取り除く測定上の比較であり、同一個体の生理的日長効果や世界一般の生態学的係数ではない。

## 生態学的に新たに分かったこと

**時間ニッチの位置と季節方向は、同じ概念ではない。** Illinoisのコヨーテとボブキャットは元研究の169共通暦日に、どちらも正の観測夜−昼qを示しながら、qと日長の元個体係数は互いに正負が逆だった。Wyomingの2有蹄類も共通193日でqの夜−昼相対値は両種で負だが、日長係数が正負逆だった。

今回の追加月内検証は、同じ暦月に限定しても**Illinoisのボブキャット−シカ**と**Wyomingのミュールジカ−ビッグホーン（元時刻系列）**の種間q差に日長との記述関連が残ることを示した。ただし、両方とも年月ブロック95%区間が**ゼロ付近まで迫る**ため、さらに複数の独立年・地域・個体群で反復する前に確証的な一般性は主張できない。

また、Illinoisのコヨーテ−ボブキャットとコヨーテ−シカでは**暦月内の点推定自体が0になったわけではない**。むしろコヨーテ−ボブキャットは新係数+0.10683で、全月係数+0.04629より絶対値が大きい。しかし年月を単位とするブートストラップ区間はゼロを含む。したがって「この関係はすべて月をまたぐ季節差の副産物」と断言するのは誤り。**月を固定すると、この2比較では不確実性が十分小さくならず、符号を支持できない**と書くのが正確。

Wyomingの元時刻系列では種間勾配差が暦月内でも正だが、**偶数・奇数2時間GPS系列では不確実性の区間がゼロを含む**。同じ原研究・元日を使っていてもGPSの測位時刻／実移動区間の違いによって解釈が変わり得るため、日長の因果的な季節機構と観測過程はまだ分離されていない。

## 月内固定では解消しない主要な交絡

天文日長は**日付から決まる天文量**である。年月ブロックで平均との差を引いても、同月内で進む日付そのものと、繁殖・採食、天気、温度、風、移動経路、標識個体の入れ替わり、GPS取得機会を独立にはできない。元の直線GPS変位qは真の活動時間の比率でなく、種間の生物学的相互作用や捕食行動を直接測っていない。Illinoisで使った元169日から167日を支持条件で選別したことも元個体・日付の新しい機会構造を持つ。

年月ブロックはIllinoisで**8**、Wyomingで**8**しかない。2000回の年月ブロック再標本化の名目95%区間は探索的で、多重検定補正や独立元studyの母集団信頼区間ではない。二つの研究DOIを、6つの種間×時計組合せで生態系反復数6に水増ししない。

旧48原GPSの日射−移動方向の事前指定外部負符号再現失敗、旧ERA5生JSON-SHA不一致12元コンテキストの歴史的HOLDはいずれも変更しない。動物GPS原ファイル・個体ID・正確な元日時と緯度経度・個体別q・年月ラベルはRSDSに公表していない。
